# DESIGN.md — デザイン原則と画面監査

この文書は、このアプリの「見た目の約束事」を固定する場所です。新しい画面や部品を作るときは、まずここに照らしてください。約束事は3段で守ります：

1. **この文書**（原則と具体値）
2. **自動テスト**（座標・寸法・色など、数値で測れる約束は E2E で固定する）
3. **公開前の全画面監査**（残りは人の目で確かめる。手順は本書末尾と `docs/HANDOVER.md` の公開前チェックリスト）

構成は2部に分かれています。**第I部は一般論**（どの作品でも使える原則の立て方・部品カタログの形式・監査手順・自動テスト化の方針）で、後からテンプレート（pwa-template）へ一般論だけを移せるようにしてあります。**第II部はこの本固有の値**（色・寸法・世界観）です。新しい作品では第II部だけを書き換えます。

---

## 第I部 一般原則（どの作品でも使える）

### 1. 原則の立て方

- **画面ごとの独自実装を増やさない。** 新しい画面は、既存の共通部品の組み合わせで作る。画面専用のボタン・帯・表示を作りたくなったら、まず「共通部品で表せないか」を疑う。どうしても専用にするときは、この文書に理由と値を書き足してから実装する。
- **見た目の決定は1か所に集約する。** 色・寸法は CSS 変数（トークン）に置き、画面側に直値を散らさない。
- **決定は版とセットで記録する。** 見た目を変えたら、その版の変更点として `docs/HANDOVER.md` に残し、この文書の該当値も同じコミットで更新する。

### 2. 家具（全画面共通の操作要素）の原則

- 読書の主画面（本文・扉・目次など）には、**全画面で同じ帯**を持たせ、同じ操作要素を**同じ位置**に置く。位置は綴じ方向で決まる（右綴じなら左下＝進む側の操作、右下＝戻る側の操作、のように）。
- 要素の位置は**絶対配置で固定**する。片方の要素がモード等で隠れても、残った要素は動かない（flex の詰め直しで位置が変わる作りにしない）。
- タップ領域は **44px 四方以上**。ただしアイコン自体は小さく薄く描き、**背景になじませる**（輪郭が要る場合も、うっすらした縁取りと僅かな陰影に留める）。操作要素が画面の主役になってはいけない。
- 帯は画面や紙の**下端にくっつけず、少し浮かせる**（浮きの量はトークンで全画面共通に保つ）。
- 状態で出し分けるのは「有無」だけにし、位置とトーンは変えない。

### 3. 色の意味

- 色は飾りではなく**意味**で割り当てる：基調色（タイトル・主要な面）、紙色（読む面）、墨色（本文）、アクセント色（見出し・区切り・現在地の印など、意味のある場所だけ）。
- **OS やブラウザ標準の色に頼らない**（標準の青いチェック、青いリンク色など）。標準部品の見た目が世界観と合わない場合は、自前で描く。
- 警告や主要ボタンのような強い意味の色は、別の意味に流用しない。

### 4. 余白と整列の原則

- 縦書きでは、並ぶ要素（柱）の**頭（上端）を完全に揃える**。要素ごとに中央寄せすると頭がばらつくのでしない。
- 項目群の縦位置は、画面の中央ではなく**少し上気味**に置き、**下の余白を広めに取る**（本の版面の考え方）。
- 並ぶ要素の**背丈は統一**する。現在地の印（背景色）などの状態表示の面積が、内容の長さで変わらないようにする。
- 寸法は「なんとなく」ではなく実測で決める。決めた値はトークンに名前を付けて残す。

### 5. 共通部品カタログの形式

共通部品は次の形式でカタログ化し、第II部に実物を置く：

| 部品 | 役割 | 寸法・トーンの決め方 |
|---|---|---|
| （クラス名） | （何のための部品か） | （タップ領域、図柄の大きさ、色、位置の規則） |

新しい部品を足したら、このカタログにも足す。カタログに無い見た目が画面にあってはいけない。

### 6. 公開前の全画面監査（手順）

版を出すたびに、公開前に必ず1回行う：

1. 全画面のスクリーンショットを撮る（撮影スクリプトで、表紙・目次・扉・本文・設定パネル・奥付＋主要な状態違い）。
2. 撮った画面を並べ、この文書の約束事と1画面ずつ照らす。観点は「崩れ・はみ出し・動作」だけでなく、**形の比率、色の意味、余白と整列、世界観との一致**まで含める。
3. 気になる寸法はピクセル実測で裏を取る（推測で済ませない）。
4. 見つけた差異は**公開前に直す**。直した内容はその版の報告に含める。直さないと決めた差異も、理由とともに報告へ残す。

### 7. 自動テスト化の方針

- **座標・寸法・色（computed style）で測れる約束は、E2E の検証として固定する。** 人の目の監査は「新しい差異の発見」、自動テストは「決めたことの回帰防止」と役割を分ける。
- **共通部品を使っているか**（全画面の帯に同じクラスの要素があるか、独自部品が混ざっていないか）は DOM 構造で検出できるので、E2E か静的チェックに寄せる。
- 逆に、世界観との一致や「なんとなく上品か」のような判断は数値化できない。無理にテスト化せず、監査（人の目）に残すと明記する。

### 8. 初回案内（ダウンロードの断り書き）の原則（v1.13.0〜）

- 配信は「初回に全部取り込む」一括方式。取り込みは Service Worker の登録と一緒に始まるため、**案内は登録より前に**出す（閉じられてから登録する）。案内より先にダウンロードが始まる作りにしない。
- 案内は表紙の上にモーダル（共通部品 `.modal`）で1回だけ出す。本文には、その本の音声の総容量をデータから動的に入れる（作品ごとに直書きしない）。閉じたら「見た」を保存し、**二度と出さない**。その端末を既に SW が制御している（＝以前の版で取り込み済み）場合も出さない。
- 文面の要点は3つに絞る：音声も一緒に届くこと／初回にまとめて取り込むので Wi-Fi 環境がおすすめなこと／一度取り込めばオフラインで読めること。ボタンは主要ボタンの色で1つだけ置く。

## 第II部 この本固有の値（『空の郵便が届くまで』）

### 1. 世界観と色

深い藍の机の上に、生成りの紙の本が載っている、という世界観で統一する。

| トークン | 値 | 意味 |
|---|---|---|
| `--indigo` / `--indigo2` | #0a1220 / （表紙の放射グラデーション） | 机（表紙側の地） |
| `--desk` / `--desk2` | #17130e 系 | 机（扉・本文側の地） |
| `--paper`（`--surface`） | #fdfaf0 | 紙（生成り） |
| `--ink`（`--text`） | #262019 | 墨（本文） |
| `--navy`（`--primary`） | #1b2a4a | 藍＝基調（題字・見出し・チェックの塗り） |
| `--gold` | #c9b87a | 金（進み具合ライン、淡い装飾） |
| `#8a6d2f` | 金茶 | 見出しラベル・柱の章番号・ノンブルなど、紙の上の控えめなアクセント |
| `--border` | #d8cfb4 | 紙の上の罫 |
| `--muted` | #6a6252 | 補足の文字 |

- チェックボックスは OS 標準の青を使わず、藍（`--indigo2` 系）で塗る自前描画（v1.12.2）。
- フォントは明朝（`--serif`）。本文の文字サイズ設定は 標準／大（1.2倍、`--font-scale`）。

### 2. 家具の具体値（本文・扉・目次で共通）

| 部品 | 役割 | 具体値 |
|---|---|---|
| `.sheet-footer` / `.page-footer` | 画面下の帯 | 高さ 44px（`--folio-band`）。中身は絶対配置で固定し、片方が隠れても動かない（v1.12.3）。帯はページ下端から `--band-lift: 10px` 浮かせる（v1.12.4。本文・扉・目次で共通。安全領域ぶんの余白とは別に、紙の中での浮きとして足す） |
| `.page-icon-btn` | 帯のアイコン（再生 ⇔・歯車マーク・文送り） | タップ領域 44×44px、図柄 19px。地の生成りに近い薄いトーンで、輪郭はうっすらした縁取りと僅かな陰影だけ（主張させない）。右綴じでは左下＝再生側、右下＝歯車マーク。左綴じでは左右を入れ替える |
| 文送り（`.sent-group`） | 本文専用：[次の文][再生/停止][前の文] | 再生の並びに同じ `.page-icon-btn` で置く。並びは**本の進み方向**で固定する（v1.13.12、ユーザー確定）：縦書き右綴じは右から左へ読み進めるので、左ボタン＝一文進む／右ボタン＝一文戻る（右ボタンは再生中・文の途中ならまず文頭へ）。メディアプレイヤーの慣習（右＝次）とは逆だが、読み方向を正とする（座標と図柄を E2E で固定。左綴じでは並びを反転させ、進む側が読み方向と一致するようにする）。図柄も向きに合わせ、左ボタンは進む方向（左向き）の送り印、右ボタンは戻る印。Media Session の next／previous も同じ文単位の送りに統一する（章移動には使わない）。耳で読むときだけ出し、目で読むでは出さない。扉・目次には付けない（v1.12.4） |
| 再生の図柄 | 本文・扉・目次（奥付は非表示のまま同じ図柄を持つ） | **スピーカー＋波紋**（線画、歯車マークと同じ stroke の作法）。右向き三角（▶）は右綴じの綴じ方向と競合して進む／戻るの誤読を招くため廃止し、向きを持たない音の記号にした（v1.13.1、ユーザー決定）。一時停止は二本線（❙❙、塗り）のまま |
| `.folio` | ノンブル | 帯の中央（絶対配置で紙の中央に固定）。「― N ―」体裁（目次は「― N / M ―」）。文字は金茶・小さめ |
| `.page-head` | 本文の柱（章題） | 帯の上に小さく金茶で。章題のみ（ページ数の 〇/〇 は出さない） |

- 目で読むモードでは、帯の再生アイコンだけが全画面で消え、歯車マークは右下のまま（v1.12.2〜）。
- 扉の下部に案内文言は置かない（v1.12.3 で削除）。
- 表紙は帯の家具を持たない代わりに、入口をモードの2ボタン（プレート型）に一本化する。バージョン表記は最下部の行の中央、設定リンクは同じ行の右端に置く（デバッグの5回タップはバージョン表記）。

### 3. 画面ごとの構成

- **表紙**：地絵は生成イラスト（全面・金枠なし）に、題字・著者名・ロゴを後付けで重ねる装丁（v1.13.3 で新装丁に差し替え。旧装丁は藍地に鳥と書店のベタ塗り＋刷り込み文字）。**v1.13.14 で地絵を紺版に差し替え**：紺の布目の地に切り絵の青い鳥が白い封筒を運ぶ姿を中央やや下に小さく置いた絵で、作中の詩集『空の郵便』（紺色の表紙＋青い鳥の切り絵の栞）と響き合わせる。前の水彩版（雨空の商店街）の地絵は `public/book/cover-art-watercolor.webp` に残し、戻せるようにしてある。題字は縦書き2列で上 12%／背側の余白 14%、色は生成り #f7f2e7（紺地の上で読める明色。v1.13.3 の濃藍から切替）。著者名は地絵のモチーフ（鳥＋封筒）の中心（幅の約50%）に合わせて下部に置き、色も生成り。ロゴは公式ロゴの線画（白＝生成り版）を小口側の上に置く（表紙幅の約7%、周囲の余白はロゴ幅の1/8以上＝LOGO.md の規定）。地絵には文字もロゴも描き込まない（生成時のゾーンルール：題字ゾーン右上・著者ゾーン下部中央・ロゴゾーン小口上は地絵で空けておく）。入口は「耳で読む」「目で読む」の2ボタン（細線の枠＋角丸）と、最下部右端の「⚙ 設定」リンクだけ（表紙タップでは開かない。v1.13.10 で B3 案に変更し、楕円ボタンは廃止）。ボタンの補足文は「朗読つき／朗読なし」固定。しおりがあるときは、ボタン上の小さな情報文（#coverResume）に「第N章のつづきから」を1回だけ示し、しおりが無いときは出さない（どちらの入口でも同じ章から再開する）。初めて読むとき（しおり無し）は、どちらの入口からもまず目次ページを開く（v1.12.4）。
- **目次**：紙の面に縦書きの柱。本文・扉と同じ帯（再生・歯車マーク・ノンブル）を持ち、「戻る」のような画面専用ボタンは置かない（開いた元への帰りは後方操作に統合、v1.12.4）。レイアウトは A案（次項）。
- **扉**：タイトルブロック（章番号・題・語り手）をひとかたまりとして中央に組む。案内文言なし。
