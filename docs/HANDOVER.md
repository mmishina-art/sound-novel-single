## 公開前チェックリスト（版を出すたびに実施。v1.12.5 で標準化）

1. `npm run verify`（lint・単体テスト・build・check:dist・check:content）が通る。
2. E2E 全件が通る（数値で固定した約束事：アイコンの位置・寸法・帯の浮き・目次の上端揃え等はここで落ちる）。
