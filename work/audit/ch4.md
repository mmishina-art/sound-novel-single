## 他章への影響（提案キーの全文検索・検証）

全7章の paragraphs を検索し、さらに新規キー13件（落ち着か／同じ行／その行／回して／話し方／少女／食い違い／代金／重すぎる／軽い／お祖父さん／切な／足りない）を現行辞書に追加するメモリ内シミュレーション（build_data.py と同一ロジック、ファイルは書いていない）で、生成結果の変化箇所を全章照合した。変化は「ch4 の意図した箇所」と下記の ch3 の同型誤り3箇所だけで、異なる読みが正しい箇所への副作用はなかった。

- 落ち着か: 出現は ch4 P1 と ch3 P1「落ち着かなくなる」の2箇所のみ。ch3 も現行は おちきかなくなる で同じ誤りであり、おちつか が正しい（同時修正になる）。
- 同じ行 / その行: 出現はそれぞれ ch4 P1 / ch4 P7 のみ。「行」単独の短いキーにしなかったのは、「行く」等の他用法（各章に多数）を壊さないため。
- 来た / 出し / 出した（既登録キー）: 「来た」は ch1 P10（適用済み・きた）と ch5 P8「西野さんが来たのは」（格納データは未反映だが きた が正しい）。「出した」は ch1 P2（適用済み）ほか ch2 等でも だした が正しい。「出し」は ch1 P9「顔を出し」、ch3 P7「引き出しへしまった」、ch7 P2「本を取り出し」等でもすべて だし 系が正しい（ch3・ch7 の格納データは ひきでし／とりでし のまま未反映）。異なる読みの箇所なし。
- 回して: 文字列としては ch1 P5「見回して」・ch7 P3「見回した」の部分一致があるが、シミュレーションで両者に変化なし（「見」の位置で「見回」が先に消費されるため「回して」キーは発火しない）。直接の「回して」は ch4 P3 のみ。
- 話し方 / 少女 / 食い違い / 代金 / 重すぎる / 足りない: 出現はそれぞれ ch4 の当該箇所のみ。他章への影響なし。
- 軽い: 「軽い」の出現は ch4 P6 のみ。なお「軽く」は ch1 P8（かるく 適用済み）と ch6 P8（格納データは かろく のまま未反映だが かるく が正しい）にある。
- お祖父さん: 出現は ch4 P8 と ch3 P3「お祖父さん譲りだねえ」の2箇所のみ。ch3 も話し手（田村さん）が他家の祖父を指す会話文で、おじいさん が正しい（同時修正になる）。地の文の「祖父《そふ》」（自分の祖父、ch1・ch5・ch7 等）にはキーが一致せず影響なし。
- 切な: 出現は ch4 P8「切なくなった」と ch3 P4「「切ない話」」の2箇所のみ。ch3 も現行は きない で同じ誤りであり、せつな が正しい（同時修正になる）。
